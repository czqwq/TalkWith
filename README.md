# TalkWith

[English README](README_EN.md)

在《我的世界》1.7.10 中与 AI 助手聊天的模组。

TalkWith 让玩家在游戏内直接与 AI 对话。你可以独自使用，也可以与队友共享同一个 AI 会话；支持自定义聊天界面，也支持原版聊天栏模式。

## 功能简介

### AI 对话
- 在游戏内通过自定义界面或原版聊天栏与 AI 对话。
- 单人模式：AI 请求由客户端直接发起，对话数据不经过服务器。
- 多人会话：多名玩家加入同一会话，共同与同一个 AI 交流，彼此能看到对方的提问与 AI 回复。

### 会话管理
- 创建、加入、退出、解散、重命名会话，并可将会话所有权转移给其他成员。
- 会话可设为公开或私密；私密会话支持邀请与加入申请审核。
- 支持设置主持人（Moderator）角色，协助管理成员与申请。
- 会话内可设置禁言、踢出成员、调整 AI 请求冷却时间。

### 聊天界面
- 自定义 AI 对话界面：查看聊天历史、消息摘要、一键清空历史。
- 设置界面：配置模型、API 地址、API 密钥与提示词。
- 可切换回原版聊天栏模式，所有功能照常可用。

### 提示词管理
- 每个会话拥有独立的提示词文件，互不干扰。
- 在游戏内即可查看、编辑、新建、保存提示词，并实时生效。
- 支持从多个提示词文件中切换当前使用的提示词。

### 队伍系统
- 创建队伍，设置所有者、长官、成员三级角色。
- 邀请、踢出、升降级成员，队伍重命名与解散。
- 队伍合并：在双方所有者同意后合并成员与数据。
- 提供管理员命令，可强制管理任意队伍。

### 安全与配置
- API 密钥在存档中以加密形式保存，加密口令由用户自行设置（AES 加密）。
- 会话数据与队伍数据均保存在存档目录中。

## 环境要求
- Minecraft 1.7.10，Forge
- 需要配置一个兼容的 AI 服务地址与 API 密钥

## 快速开始
1. 将模组放入 `mods` 文件夹。
2. 进入游戏，使用 `/talkwith config` 相关命令或打开设置界面，填写 AI 服务地址与 API 密钥。
3. 使用 `/talkwith open` 打开 AI 对话界面开始聊天。
4. 如需与队友共享，创建或加入一个多人会话。
